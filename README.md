# EduGenie: Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant web app that helps users with smart, personalized educational recommendations and answers using Google Gemini.

## Features
- **AI Learning Support:** Get instant answers and explanations powered by Google Gemini.
- **Interactive Interface:** Clean and responsive web frontend for seamless interaction.
- **Fast Backend:** Built with FastAPI for high-performance API handling.

## Tech Stack
- **Backend:** Python (FastAPI)
- **AI Model:** Google Gemini AI
- **Frontend:** HTML, CSS, JavaScript

## Project Structure
- `gemini_model.txt` - AI model configuration and details
- `main.py` - FastAPI backend application
- `index.html` - Frontend web interface
- `requirements.txt` - Python project dependencies
- `style.css` - Custom styles for the web pages
